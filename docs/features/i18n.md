## 実装内容

### 1. 型定義 (`src/i18n/types.ts`)

- `Locale`: `"ja" | "en"`
- `Dictionary`: ネストされた辞書インターフェース
- `DictionaryKey`: `DotPaths<Dictionary>` ユーティリティ型で `t()` の引数を型チェック

### 2. 翻訳辞書 (`src/i18n/dictionaries/`)

| カテゴリ | 内容 |
|---------|------|
| `common.*` | キャンセル、削除、閉じる、再試行、ダウンロード、コピー、保存 等 |
| `nav.*` | サイドバーメニュー項目 |
| `dashboard.*` | ダッシュボードのタイトル・ラベル |
| `transcription.*` | 文字起こし画面のテキスト |
| `history.*` | 履歴画面のテキスト |
| `settings.*` | 設定画面のテキスト（最多） |
| `errors.*` | エラーカテゴリラベル |
| `result.*` | 結果表示のトースト |
| `dev.*` | 開発メニューのテキスト |

### 3. コアシステム (`src/i18n/index.tsx`)

| エクスポート | 説明 |
|-------------|------|
| `createI18n(locale?)` | i18nインスタンス生成（locale, setLocale, t, dict） |
| `I18nProvider` | Context.Provider ラッパー。`locale` prop を受け取る |
| `useI18n()` | コンポーネント内でi18nを取得するフック |

### 4. 統合パターン

- `AppLayout` が `settings.language()` を `I18nProvider` の `locale` prop に渡す
- 設定画面での言語変更は `setLocale()` を直接呼び出して即座に反映
- `I18nProvider` 内の `createEffect` は `on(() => props.locale, ...)` で明示的に追跡し、リアクティブループを防止
- 日付フォーマットは `locale()` に基づき `"ja-JP"` / `"en-US"` を切り替え
